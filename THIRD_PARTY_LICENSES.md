### Notes / Note
- **SheetJS Community Edition** (`xlsx`) is installed from the official SheetJS CDN tarball
  (`https://cdn.sheetjs.com/`), Apache-2.0. Only the build process downloads it: the website never
  contacts external servers.
- **Inter Tight** and **JetBrains Mono** fonts (via Fontsource) are licensed under the SIL Open Font
  License 1.1 and are served from the same origin as the site.
- **pdf.js** (`pdfjs-dist`, Apache-2.0, Mozilla) renders the page thumbnails of the PDF tools. Its worker script
  and the standard font files (Foxit and Liberation fonts, with their own licenses in
  `node_modules/pdfjs-dist/standard_fonts/`) are copied into the build and served from the same origin,
  never from a CDN. **pdf-lib** (MIT) creates the merged and split PDFs; `pako` is MIT AND Zlib.
- **Apache ECharts** is a project of the Apache Software Foundation (Apache-2.0); see its NOTICE file.
- **EFF Large Wordlist for Passphrases** (7776 words) by the Electronic Frontier Foundation, licensed
  [CC BY 3.0 US](https://creativecommons.org/licenses/by/3.0/us/), used by the password generator
  (`public/wordlists/eff-large.txt`, served from the same origin). Source:
  https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases. Change: the dice-number column
  was removed, leaving one word per line. / Lista di parole EFF (7776), licenza CC BY 3.0 US; modifica:
  tolta la colonna dei numeri dei dadi.
- **ISTAT** (Istituto nazionale di statistica) data for the tax code tool: the list of Italian municipalities
  with their cadastral codes and province abbreviations, "Codici dei comuni, delle province e delle regioni"
  (https://www.istat.it/classificazione/codici-dei-comuni-delle-province-e-delle-regioni/), licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) (https://www.istat.it/note-legali/). Changes: only
  the name, cadastral code and province abbreviation are kept, as compact JSON
  (`public/data/luoghi.json`, same origin, regenerated by `scripts/update-places.mjs`); the historical
  province codes 001-099 also feed `vat-offices.ts`. Suppressed municipalities come from the public ISTAT SITUAS
  report 128 (https://situas-servizi.istat.it/publish/reportspooljson?pfun=128), same licence. / Dati ISTAT
  (CC BY 4.0), rielaborati in formato compatto; comuni soppressi dal report SITUAS 128.
- **ANPR** (Anagrafe nazionale della popolazione residente, Ministero dell'Interno), table of foreign states
  `tab_Stati_Esteri.xlsx` (https://github.com/italia/anpr), licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes: only the ISTAT name and the cadastral
  code (Z...) are kept. / Stati esteri con codice Z dalla tabella ANPR (CC BY 4.0).
- **IBAN lengths and formats** follow the public IBAN Registry of SWIFT (ISO 13616); the **codice fiscale**
  rules are those of the DM 23 December 1976; the IBAN mod-97, the Italian CIN and the partita IVA check
  digit are original TypeScript implementations of public algorithms: no third-party code.
- **MD5 and SHA-256** (streaming, for very large files) in the hash tool are original TypeScript
  implementations of the public algorithms (RFC 1321, FIPS 180-4): no third-party code.
